# Global Sales Intelligence Dashboard

An interactive sales analytics dashboard built with Python, Pandas, Plotly and Streamlit.

**Live demo:** https://international-sales-dashboardgit-xcewga5fmsea5zpp7zf6xc.streamlit.app/

## Important note
This is a **self-practice portfolio project**, not paid client work. The dataset is **synthetic (randomly generated sample data)** and does not represent a real company.

## Features
- KPI cards: Total Revenue, Total Profit, Total Orders, Units Sold
- Monthly revenue trend
- Revenue by city and by category
- Top 5 products by revenue
- Filters for city, category and date range
- Transaction table with CSV download
- Responsive layout for laptop, tablet and mobile

## Tech stack
Python, Pandas, NumPy, Plotly, Streamlit

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```
